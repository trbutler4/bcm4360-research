# Experiment records

Create one Markdown record per bounded question, named `YYYY-MM-DD-short-description.md`, using [the template](TEMPLATE.md).

Keep raw inputs, outputs, captures, private logs, vendor binaries, and firmware outside Git. A committed record should contain sanitized commands/findings, exact source pins, provenance, and enough detail to distinguish a reproduced observation from an inference.
